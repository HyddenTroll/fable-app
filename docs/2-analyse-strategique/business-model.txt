========================================
BUSINESS MODEL
========================================
Projet : Fable (livre dont tu es le héros + IA)
Date : 03/09/2026
NOTE : les détails chiffrés, les prix, les marges et les
scénarios sont dans economie-app.txt (document de référence).
Ce fichier est la synthèse stratégique.

--------------------------------------------------------
1. MODÈLE DE REVENUS (choix retenu - 3 niveaux)
--------------------------------------------------------
MODÈLE À 3 NIVEAUX (voir economie-app.txt pour les chiffres) :
1. ESSAI GRATUIT LIMITÉ : les 5 premiers chapitres offerts
   (= premier arc du roman + cliffhanger) => création de l'envie.
2. FABLE+ : abonnement 4,99 €/mois = chapitres de texte
   illimités, tous genres, personnalisation complète.
3. CRÉDITS : images à la demande (1 image = 3 crédits),
   séparées de l'abonnement => monétisation "à la carte",
   le produit à plus forte marge.
Justification : le freemium est la norme du secteur (AI Dungeon,
Episode, Choices) ; le système de crédits image est validé par
AI Dungeon (crédits mensuels par palier) et Google (crédits
Flow).

--------------------------------------------------------
2. STRUCTURE DE COÛTS (détail dans economie-app.txt)
--------------------------------------------------------
- Structure : vrai roman, 1 génération IA = 1 chapitre
  (~800-1500 mots).
- Coût texte : ~0,002 $/chapitre (GPT-5.6 Luna), ~0,018 $
  (Claude Sonnet 5 pour les fins).
- Coût image : ~0,02 $/image (FLUX.1 Dev via fal.ai), DALL-E 3
  (~0,05 $) en option haute qualité.
- Un roman = 10-15 chapitres = ~0,02 à 0,03 $ en Luna.
- Hébergement Vercel : gratuit (plan Hobby) au démarrage.
- Base Supabase : gratuit jusqu'à ~50k MAU.
- Domaine : ~10-15 €/an.
- Frais stores : 15 % (sous 1 M$ de CA) à 30 % sur les
  abonnements et achats intégrés.

--------------------------------------------------------
3. REVENUS ESTIMÉS (détail dans economie-app.txt)
--------------------------------------------------------
- MAU 5 000, 5 % conversion : ~250 Fable+ + packs
  => ~1 870 €/mois de revenus, ~350 $/mois de coûts IA.
- MAU 20 000 : ~7 480 €/mois, ~1 400 $/mois de coûts.
- MAU 100 000 : ~37 400 €/mois, ~7 000 $/mois de coûts.
=> Coûts IA ≈ 18-19 % des revenus. Rentable très tôt.

--------------------------------------------------------
4. SEUIL DE RENTABILITÉ
--------------------------------------------------------
- Coûts fixes mensuels : ~1-3 € au départ, ~25-50 € dès
  50k MAU (Supabase/analytics).
- Coût texte : ~0,001 $/chapitre (Luna).
- Coût image : ~0,02 $/image (FLUX Dev).
- Coût par utilisateur actif/mois (gratuit) : ~0,20 $
  réaliste, ~0,75 $ worst case.
- Marge par abonné 4,99 € : ~3,50 € net après IA et store.
- POINT MORT : ~80-100 MAU (5 % conversion) couvrent déjà les
  coûts. La rentabilité est quasi immédiate.

--------------------------------------------------------
5. DÉCISION
--------------------------------------------------------
- Lancer en FREEMIUM dès le départ : gratuit généreux pour
  l'acquisition, Fable+ à 4,99 €/mois, packs de crédits images.
- Texte : GPT-5.6 Luna (volume) + Claude Sonnet 5 (fins).
- Images : FLUX.1 Dev via fal.ai (~0,02 $/image).
- Réviser les prix/quotas après les premiers chiffres réels
  (métriques : coût IA/MAU, conversion, usage des crédits).
- Options futures : univers premium, version éducation
  (licences scolaires).
