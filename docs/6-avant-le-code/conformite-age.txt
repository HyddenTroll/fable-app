3. RGPD / DONNÉES DES MINEURS (France) - RÈGLES À SUIVRE
================================================================
- SEUIL FRANCE : 15 ans. En dessous de 15 ans, le consentement
  au traitement des données doit être CONJOINT (mineur +
  parent) pour les services en ligne (art. 8 RGPD + loi
  Informatique et Libertés - seuil abaissé à 15 en France).
- RGPD par défaut : 16 ans (13-16 selon les pays) => si l'app
  est utilisée dans d'autres pays de l'UE, vérifier le seuil
  national.
- COPPA (USA) : moins de 13 ans = consentement parental
  vérifiable avant toute collecte de données personnelles.
- IMPLICATION CONCRÈTE POUR FABLE :
  * Si l'utilisateur déclare -15 ans : afficher une ÉTAPE DE
    CONSENTEMENT PARENTAL à l'inscription (email du parent,
    ou mention claire "demande à un parent de valider").
  * Si -13 ans et marché US : consentement parental vérifiable
    (email de confirmation du parent).
  * Interface et mentions adaptées aux enfants (langage simple).
  * Minimiser les données : pas de pub, pas de tracking tiers,
    pas de données inutiles.
- BASE LÉGALE recommandée : CONTRAT (exécution du service)
  plutôt que consentement marketing => évite une partie du
  consentement parental, MAIS la prudence s'impose (CNIL).

4. CHANGEMENT D'ÂGE (décision - sous réserve du légal)
================================================================
- L'utilisateur PEUT modifier son âge (décision produit).
- RÈGLES DE SÉCURITÉ :
  * CHANGEMENT VERS LE HAUT (ex : 14 -> 18+) : autorisé avec
    une confirmation explicite + avertissement sur le contenu
    qui devient accessible. (Un mineur ne peut pas légalement
    contourner : la confirmation n'est pas une vérification
    d'identité, c'est un garde-fou.)
  * CHANGEMENT VERS LE BAS (ex : 18 -> 14, pour accéder au
    mode doux) : autorisé librement (restriction de contenu,
    pas de risque).
  * AUCUN contournement de l'âge vers le haut sans confirmation
    (double tap + texte clair).
- LIMITE PRAGMATIQUE : ne pas collecter de pièce d'identité au
  MVP (trop intrusif, risque RGPD). La confirmation suffit pour
  la conformité "efforts raisonnables" (art. 8(2)).
- À DOCUMENTER dans la politique de confidentialité : comment
  l'âge est utilisé et modifiable.
