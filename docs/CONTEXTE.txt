========================================
PROJET : FABLE
========================================
Application mobile "livre dont tu es le héros"
avec texte généré par intelligence artificielle.

Date de création : 03/09/2026

========================================
DÉCISIONS PRISES
========================================
- Nom du projet : Fable
- Type : application mobile (iOS + Android)
- Concept : livre dont vous êtes le héros, l'histoire est
  générée dynamiquement par une IA en temps réel.
- Emplacement du projet : D:\Fable
- Déploiement prévu : GitHub (code source) + Vercel
- Langue cible : français (créneau quasi vide)
- Analyses stratégiques réalisées (voir dossiers 1, 2, 3)

========================================
STACK
========================================
- Mobile : Expo / React Native (TypeScript)
  -> Un seul code pour iOS + Android.
  -> Export web possible => déploiement Vercel.
  -> Test sur téléphone via l'app Expo Go.
- Backend : Vercel Serverless Functions (API)
  -> La clé IA reste côté serveur (sécurité).
  -> Pas de serveur à gérer, gratuit pour démarrer.
- Base de données : Supabase (Postgres, gratuit)
- Navigation : Expo Router | État : Zustand
- Monorepo : apps/mobile + api + packages/shared + prompts + docs

========================================
STRUCTURE & MODÈLE ÉCONOMIQUE (résumé)
========================================
STRUCTURE : un vrai roman. Histoire = roman (10-15 chapitres).
1 génération IA = 1 chapitre (~800-1500 mots). Choix 2-5 en
fin de chapitre. (On ne copie pas les codes du gamebook.)
RÉFÉRENCE D'ÉCRITURE : 5-ecriture-narrative/
- structure-romans-tous-genres.txt (arcs narratifs, chapitres,
  codes de tous les genres, techniques d'écriture).
- chefs-doeuvre-litteraires.txt (étude des plus grands romans :
  7 mécanismes de génie, leçons transmissibles à l'IA, les
  références par genre - qualité littéraire et règles anti-AI-slop).

MODÈLE À 3 NIVEAUX (détail : 2-analyse-strategique/economie-app.txt) :
- Essai gratuit limité : 5 premiers chapitres offerts
  (cliffhanger) puis blocage.
- Fable+ : 4,99 €/mois (texte illimité), 39,99 €/an.
- Crédits : images à la demande, 1 image = 3 crédits,
  packs 0,99 à 9,99 € (séparés de l'abonnement).
- Coûts : texte ~0,002 $/chapitre (Luna), image ~0,02 $
  (FLUX Dev), point mort dès ~60-80 MAU.
- Rentable très tôt ; coûts IA ≈ 18-19 % des revenus.
